# Shourya-Ecommerce-Sales
Collected and consolidated e-commerce sales data from Kaggle datasets to build a structured analytical dataset.
Cleaned and transformed raw data by handling inconsistencies, missing values, and formatting issues to improve data quality.
Analyzed sales, orders, revenue, profit, quantity, and customer/product performance to identify key business trends and patterns.
Developed an interactive Power BI dashboard with KPI cards, charts, filters, and drilldowns to enable data-driven business analysis.
Visualized performance across key dimensions such as time, category, product, region, and payment mode to identify high- and low-performing segments.
Translated analytical findings into actionable business insights, enabling users to monitor performance and identify areas for improvement.
